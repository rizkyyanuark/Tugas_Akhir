# texsupport.ruc-jds

LaTeX author support files for the [Jurnal Riset Aplikasi Ilmu Data dan Sistem][https://ejournal.unesa.ac.id/index.php/rapids]


## Contents

The following files are given in the repository (or directly in `.zip` archive):

- `RAPIDS_sample.tex` - a sample article
- `rapidsart.cls` - journal class file
- `apacite.sty` - Bibtex APA style
- `biblio.bib` - Bibtex DB sample
